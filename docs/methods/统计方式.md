### 第一步：公共统计量（每个 `(condition, candidate)` 对，按 comparison class 分别算）

对每个主诉 c、每个候选检查 y，先算共现计数，再导出这些量：

| 量                | 公式                                                        | 含义                    |
| ---------------- | --------------------------------------------------------- | --------------------- |
| `n_adm`          | 同时有 c 和 y 的住院数                                            | 共现计数                  |
| `share`          | `n_adm / condition_support`                               | 条件概率 P(y\|c)，「最可能」    |
| `baseline_share` | `baseline_adm / total_adm`                                | 全队列基线 P(y)            |
| `selectivity`    | `share / baseline_share`                                  | **lift**，「比基线高几倍」     |
| `p_value`        | 单侧二项 `P(X≥n_adm; n=condition_support, p0=baseline_share)` | 关联显著性                 |
| `q_value`        | 每个 condition 内跨候选做 **BH-FDR**                             | 多重检验校正                |
| `wilson_lower`   | Wilson 95% 区间下界                                           | 小样本置信下限               |
| `reliability`    | `log10(max(1, 1 + n_adm − psr_nco_min)) + psr_r`          | 可靠性因子（Li 2020 PSR 定义） |
| `psr`            | `share × selectivity × reliability`                       | 概率×特异性×可靠性            |
| `sr`             | `selectivity × reliability`                               | 特异性×可靠性（去掉概率项）        |

### 第二步：四种语义 = 不同的「筛选门槛 + 排序键」

|语义|筛选门槛|排序键（降序）|gold =|
|---|---|---|---|
|likelihood|无（仅按 share）|`share`|最可能开|
|selectivity|`q_value≤fdr_q` 且 `share≥0.15` 且 `selectivity≥1.5`|`selectivity`|最判别（lift）|
|psr|`n_adm≥10` 且 `share≥0.01`|`psr`|PSR 最高|
|specificity×reliability|`n_adm≥10` 且 `share≥0.01`|`sr`|SR 最高|
