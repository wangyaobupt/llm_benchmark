### V 2-LLMs 生成

- 基于特征的组合，LLMs
    
    |特征|数据来源|抽取方式|
    |---|---|---|
    |age_band|人口学 sidecar（`anchor_age + (admit_year − anchor_year)`）|结构化·确定性|
    |sex|人口学 sidecar|结构化·确定性|
    |symptom| `symptom_reported` 事件（assertion=present）|结构化·确定性|
    |sign|出院小结「体格检查」章节|**NER·LLM**|
    |physiologic_flag| `vital_measured` 结构化事件|结构化·确定性（数值阈值化，9 个 flag）|
    |past_condition|ICD Z 80-Z 99 + 慢性词表（ICD 轨）；出院小结（NER 轨）|确定性 + **NER·LLM 双轨**|
    |medication|入院用药事件|结构化·确定性（类别归并）|
    |absent|否定症状事件|结构化·确定性|
    
- **9 个生命体征 flag**（`physiologic_flag`，不进 sign，避免重复计数）：tachycardia(HR>100) / bradycardia(<60) / fever(≥37.0°C) / hypothermia(<35.0°C) / hypoxia(SpO2<92%) / tachypnea(RR>20) / bradypnea(<12) / hypotension(SBP<90) / hypertension(SBP≥140)。
