# MIMIC-IV 出题全流程字段需求映射

> **生成日期**: 2026-08-07
> **数据版本**: MIMIC-IV v3.1 (hosp/icu) + MIMIC-IV-ED v2.2 (ed) + MIMIC-IV-Note v2.2 (note)
> **分析方法**: 从五类题型的临床数据需求出发，直接映射到 MIMIC 表和字段，不经过任何中间聚合层
> **分析依据**: `mcq_generation/question_types.md`（题型字段规范）、`data/MIMIC-IV_全模块字段解析.md`（MIMIC 字段定义）

---

## 一、临床决策链与五类题型

出题围绕一条完整的临床就诊时间线展开，每一道题锁住流程中的一个决策点：

```
患者信息 ─→ ① 检查检验选择 ─→ ② 临床诊断 ─→ ③ 治疗处置 ─→ ④ 转诊科室 ─→ ⑤ 离院指导
             (下一步检查)      (最可能诊断)   (最适当治疗)   (最适当科室)   (随访计划)
```

核心设计原则：**每道题的「题干信息字段」和「答案来源字段」严格分离**——答案来源字段不能泄漏进题干。每道题的题干字段分为：
- **题干信息**：必定出现，提供患者基本背景
- **条件题干信息**：仅在会影响答案判断时加入（如生命体征不稳定会改变检查/治疗优先级）

## 三、临床数据类别 → MIMIC 表字段映射

以下逐一将 14 个临床数据类别映射到 MIMIC 数据库中的表和具体字段，并标注推荐来源和适用条件。

### 1. 人口统计（年龄、性别）

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `patients` | `gender` | 性别（M/F） |
| `patients` | `anchor_age` | 锚定年龄 |
| `patients` | `anchor_year` | 锚定年份（去标识化） |
| `admissions` | `admittime` | 入院时间，与 anchor_age/anchor_year 计算就诊时年龄 |

**计算**: `age_at_encounter = anchor_age + year(admittime) - anchor_year`

### 2. 主诉

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `discharge` (note) | `text` | 出院小结全文，从中解析 Chief Complaint 章节 |
| `triage` (ed) | `chiefcomplaint` | 急诊分诊时记录的主诉（急诊患者） |

**说明**: 主诉是自由文本，需从 `discharge.text` 的 "Chief Complaint" 标题章节提取。急诊患者可辅助参考 `triage.chiefcomplaint`。

### 3. 现病史（HPI）

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `discharge` (note) | `text` | 从中解析 History of Present Illness 章节 |

**说明**: 现病史仅存在于出院小结文本中，是描述症状起病方式、持续时间和变化过程的自由文本段落。

### 4. 生命体征

MIMIC 中生命体征分散在多个模块，按就诊场景选择来源：

#### 来源 A: 急诊分诊 `triage`（推荐首选）

患者到达急诊时的首次客观测量，与题干「入院时表现」语义最匹配。

| 字段 | 含义 | 单位 |
|---|---|---|
| `temperature` | 体温 | 华氏度（需转°C） |
| `heartrate` | 心率 | bpm |
| `resprate` | 呼吸频率 | 次/分 |
| `o2sat` | 血氧饱和度 | % |
| `sbp` | 收缩压 | mmHg |
| `dbp` | 舒张压 | mmHg |
| `acuity` | ESI 分级（1-5） | 等级，越小越紧急 |

#### 来源 B: 急诊期间 `vitalsign`（多次测量）

字段与 triage 相同（temperature/heartrate/resprate/o2sat/sbp/dbp/pain），增加 `rhythm`（心律文本描述）和 `charttime`（记录时间）。可取首次值或急诊期间趋势。

#### 来源 C: ICU 床旁 `chartevents`（ICU 患者）

通过 `icustays.hadm_id` 关联，取入 ICU 后首小时测量值。需 join `d_items` 获取项目定义。

| d_items.itemid | 含义 |
|---|---|
| 220045 | 心率 |
| 220050 / 220051 / 220052 | 有创动脉收缩压/舒张压/平均压 |
| 220179 / 220180 / 220181 | 无创收缩压/舒张压/平均压 |
| 220210 | 呼吸频率 |
| 223762 | 体温（摄氏度） |
| 220277 | 脉氧饱和度 |

#### 来源 D: 门诊 `omr`（补充）

`omr.result_name = 'Blood Pressure'` 对应的 `result_value`（格式 "收缩压/舒张压"），以及 `Weight`、`BMI (kg/m2)` 等。

### 5. 既往史

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `discharge` (note) | `text` | 从中解析 Past Medical History 章节 |

**说明**: 既往史指「当前临床决策前已经存在的疾病及相关医疗历史」。出院小结中的 Past Medical History 章节是权威来源。

### 6. 用药史（入院前用药）

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `discharge` (note) | `text` | 从中解析 Medications on Admission 章节 |
| `medrecon` (ed) | `name`, `gsn`, `ndc`, `etcdescription` | 急诊用药核对——患者报告的入院前用药 |

**说明**: 出院小结的 Medications on Admission 章节记录入院前用药。急诊模块的 `medrecon` 表也记录患者到达急诊时自报的正在服用药物，可互为补充。

### 7. 检查/检验医嘱

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `poe` | `order_type` | 医嘱类型（Lab / Imaging） |
| `poe` | `order_subtype` | 医嘱子类型（如 Chemistry、CT Head 等） |
| `poe` | `transaction_type` | 操作类型（取 New） |
| `poe` | `ordertime` | 医嘱下达时间 |
| `poe_detail` | `field_name`, `field_value` | 医嘱明细（EAV 模型，如 Specimen Type、Body Part 等） |

**说明**: 筛选 `order_type IN ('Lab', 'Imaging')` 且 `transaction_type = 'New'` 的医嘱。`poe_detail` 通过 `poe_id + poe_seq` 关联 `poe`。

### 8. 检查报告（影像/心电等）

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `radiology` (note) | `text` | 放射学报告全文（含 Indication/Findings/Impression） |
| `radiology` (note) | `charttime` | 检查时间 |
| `radiology_detail` (note) | `field_name`, `field_value` | 报告结构化属性（exam_name、exam_code、cpt_code） |

**说明**: 筛选 `note_type = 'RR'`（正式报告）。通过 `radiology_detail` 的 `field_name = 'exam_name'` 可识别检查类型（如 CHEST X-RAY、CT HEAD 等）。

### 9. 实验室检验结果

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `labevents` | `itemid` | 检验项目标识 → join d_labitems |
| `labevents` | `value`, `valuenum` | 检验结果（文本/数值） |
| `labevents` | `valueuom` | 计量单位 |
| `labevents` | `ref_range_lower`, `ref_range_upper` | 参考范围 |
| `labevents` | `flag` | 异常标志（abnormal） |
| `labevents` | `charttime` | 标本采集时间 |
| `labevents` | `specimen_id` | 标本标识（同一标本多项检验） |
| `d_labitems` | `label`, `fluid`, `category` | 项目名称、标本类型、检验类别 |

**常用检验项目**: 50912 Creatinine、50971 Potassium、50983 Sodium、51221 Hematocrit、51222 Hemoglobin、51265 Platelet Count、51301 WBC、51003 Troponin T、50820 pH、50821 pO2 等。

### 10. 诊断

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `diagnoses_icd` | `icd_code`, `icd_version` | ICD 诊断编码 |
| `diagnoses_icd` | `seq_num` | 诊断序号（seq_num=1 为主诊断） |
| `d_icd_diagnoses` | `long_title` | 诊断名称（英文描述） |
| `diagnosis` (ed) | `icd_code`, `icd_version`, `icd_title` | 急诊阶段诊断（与住院诊断可能不同） |

**说明**: 住院诊断来自 `diagnoses_icd`（出院后编码），`seq_num=1` 为主诊断。急诊诊断来自 ed 模块 `diagnosis` 表，反映急诊阶段的初步判断。`d_icd_diagnoses` 提供 ICD 编码到诊断名称的字典映射。

### 11. 药物处方

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `prescriptions` | `drug` | 药物名称（取 drug_type=MAIN） |
| `prescriptions` | `dose_val_rx`, `dose_unit_rx` | 剂量值和单位 |
| `prescriptions` | `route` | 给药途径（IV/PO/IM/SC 等） |
| `prescriptions` | `prod_strength` | 药品规格 |
| `prescriptions` | `form_rx` | 剂型（TABLET/VIAL/BAG 等） |
| `prescriptions` | `doses_per_24_hrs` | 每 24 小时给药频次 |
| `prescriptions` | `starttime`, `stoptime` | 处方起止时间 |

**说明**: 筛选 `drug_type = 'MAIN'`（主药成分），排除 BASE（溶媒）和 ADDITIVE（添加剂）。`prescriptions` 记录的是处方医嘱，非实际给药。

### 12. 手术/操作记录

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `procedures_icd` | `icd_code`, `icd_version` | ICD 操作编码 |
| `procedures_icd` | `chartdate` | 操作日期 |
| `procedures_icd` | `seq_num` | 操作序号 |
| `d_icd_procedures` | `long_title` | 操作名称 |

**说明**: `procedures_icd` 是出院后编码（用于计费），覆盖外科手术、机械通气、导管置入、内镜、透析等。ICD-10-PCS 的编码粒度远高于 ICD-9-PCS。

### 13. 科室/转诊记录

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `services` | `curr_service` | 当前负责治疗的科室（MED/SURG/CMED/CSURG/NSURG 等） |
| `services` | `prev_service` | 前一科室（转科路径） |
| `services` | `transfertime` | 转科时间 |
| `transfers` | `careunit` | 物理病房（MICU/SICU/CCU/Emergency Department 等） |
| `transfers` | `eventtype` | 事件类型（admit/transfer/discharge/ed） |
| `transfers` | `intime`, `outtime` | 进入/离开该单元的时间 |
| `admissions` | `admission_location` | 入院前位置（如 EMERGENCY ROOM、PHYSICIAN REFERRAL） |
| `admissions` | `discharge_location` | 出院去向（HOME/SKILLED NURSING FACILITY/REHAB/HOSPICE 等） |
| `edstays` (ed) | `disposition` | 急诊离开去向（HOME/ADMITTED/TRANSFER/EXPIRED 等） |

**说明**: `services` 记录负责治疗的医疗团队（科室），`transfers` 记录患者的物理位置（病房）。一次住院可能有多次转科，取最终负责科室 `curr_service` 作为主要科室。`admissions.discharge_location` 直接给出离院去向。

**services 科室代码**: MED 内科、SURG 外科、CMED 心内科、CSURG 心外科、NSURG 神经外科、NMED 神经内科、OMED 肿瘤科、TRAUM 创伤外科、ORTHO 骨科、TSURG 胸外科、VSURG 血管外科、GYN 妇科、OBS 产科、GU 泌尿外科、ENT 耳鼻喉科、PSYCH 精神科、DENT 口腔科、NB 新生儿。

### 14. 出院/随访记录

| MIMIC 表 | 字段 | 说明 |
|---|---|---|
| `discharge` (note) | `text` | 出院小结全文，从中解析 Follow-up Instructions 章节 |
| `discharge` (note) | `note_type` | 文档类型（DS=出院小结，AD=补充记录） |

**说明**: 出院小结还包含 Discharge Medications（出院用药）、Discharge Diagnosis（出院诊断）、Discharge Condition（出院状态）等章节。`question_types.md` 将出院记录作为题型 5 的答案来源，从中提取随访计划、复查安排、危险信号等内容。

## 四、逐题型字段需求分析

### 题型 ① 检查检验选择 (Clinical Investigation Selection)

> **题目问什么**: 给定患者表现，真实世界数据中最可能被选择的下一项检查/检验是哪项？

**题干信息字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 年龄 | patients(`anchor_age`, `anchor_year`) + admissions(`admittime`) |
| 性别 | patients(`gender`) |
| 主诉 | discharge(`text` → Chief Complaint) |
| 现病史 | discharge(`text` → History of Present Illness) |
| 既往史 | discharge(`text` → Past Medical History) |
| 入院用药 | discharge(`text` → Medications on Admission) |

**条件题干信息字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 生命体征 | triage(`temperature`, `heartrate`, `sbp`, `dbp`, `o2sat`, `resprate`, `acuity`); 或 chartevents(itemid 220045 等) |

**答案来源字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 检查/检验医嘱 | poe(`order_type` IN Lab/Imaging, `order_subtype`) + poe_detail(`field_name`, `field_value`) |

**信息隔离**: 检查结果（labevents/radiology）、诊断（diagnoses_icd）、处方（prescriptions）不得用于构造本题型的条件特征或答案，否则会通过检查后信息或最终诊断泄漏答案。

### 题型 ② 临床诊断 (Clinical Diagnosis)

> **题目问什么**: 整合症状、体征、检查检验结果，从多个合理候选诊断中选择最可能的诊断。

**题干信息字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 年龄 | patients(`anchor_age`, `anchor_year`) + admissions(`admittime`) |
| 性别 | patients(`gender`) |
| 主诉 | discharge(`text` → Chief Complaint) |

**条件题干信息字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 既往史 | discharge(`text` → Past Medical History) |
| 用药史 | discharge(`text` → Medications on Admission) |
| 生命体征 | triage / vitalsign / chartevents |
| 检查报告 | radiology(`text`); radiology_detail(`exam_name`) |
| 检验结果 | labevents(`value`, `valuenum`, `flag`) + d_labitems(`label`) |

**答案来源字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 诊断（主诊断+其他诊断） | diagnoses_icd(`icd_code`, `seq_num`) + d_icd_diagnoses(`long_title`) |

**特别注意**: 诊断题应保留至少一项关键检查或检验结果作为题干信息。

### 题型 ③ 治疗与处置 (Treatment and Management)

> **题目问什么**: 根据患者信息、检查结果和已确定的诊断，选择当前最适当的治疗或处置措施。
> **覆盖范围**: 药物治疗、非药物治疗、支持治疗、操作/手术、紧急处置、观察/住院

**题干信息字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 年龄/性别 | patients + admissions |
| 主诉 | discharge(`text` → Chief Complaint) |
| 诊断 | diagnoses_icd(`seq_num=1`) + d_icd_diagnoses(`long_title`) |

**条件题干信息字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 既往史 | discharge(`text` → Past Medical History) |
| 用药史 | discharge(`text` → Medications on Admission) |
| 生命体征 | triage / vitalsign / chartevents |
| 检查报告 | radiology(`text`); radiology_detail(`exam_name`) |
| 检验结果 | labevents + d_labitems |

**答案来源字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 药物处方 | prescriptions(`drug`, `dose_val_rx`, `dose_unit_rx`, `route` 等, drug_type=MAIN) |
| 手术/操作 | procedures_icd(`icd_code`) + d_icd_procedures(`long_title`) |

### 题型 ④ 转诊与科室选择 (Referral and Specialty Selection)

> **题目问什么**: 根据患者信息和诊断，选择当前最适当的医疗服务或科室。
> **覆盖范围**: 紧急程度、服务层级、具体专科

**题干信息字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 年龄/性别 | patients + admissions |
| 主诉 | discharge(`text` → Chief Complaint) |
| 诊断 | diagnoses_icd(`seq_num=1`) + d_icd_diagnoses(`long_title`) |

**条件题干信息字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 既往史 | discharge(`text` → Past Medical History) |
| 用药史 | discharge(`text` → Medications on Admission) |
| 生命体征 | triage / vitalsign / chartevents |
| 检查报告 | radiology + radiology_detail |
| 检验结果 | labevents + d_labitems |

**答案来源字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 科室/转诊 | services(`curr_service`, `prev_service`); transfers(`careunit`); admissions(`discharge_location`); edstays(`disposition`) |

**特别注意**: 紧急程度、转诊时限、服务层级不预设为独立字段，应根据主诉、生命体征、诊断判断，或从 services/transfers 记录中提取。

### 题型 ⑤ 离院指导与随访 (Discharge Advice and Follow-up)

> **题目问什么**: 根据诊断、治疗经过和离院时状态，选择最适当的离院指导或随访计划。

**题干信息字段:**

| 临床数据 | MIMIC 表·字段 |
|---|---|
| 年龄/性别 | patients + admissions |
| 诊断 | diagnoses_icd(`seq_num=1`) + d_icd_diagnoses(`long_title`) |

**条件题干信息字段:**
