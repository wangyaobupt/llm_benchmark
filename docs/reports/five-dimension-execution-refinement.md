# 五维执行路径细化：gold 方案、评测体系与 NER/RE 开展（调研主报告）

> 调研日期：2026-08-16
> 输入：本次三份新证据笔记——[检查检验+诊断](five-dim-gold-survey-tests-diagnosis.md)（14 个评测体系、5 张关键表深析）、[治疗+转诊+随访](five-dim-gold-survey-treatment-referral-followup.md)（6 个规范性工具、5 张关键表深析）、[实体关系抽取开展方案](ner-re-execution-survey.md)（5 张 IAA/难度表深析）——以及此前四份文档（[五维 MCQ 综述](benchmark-five-dimension-evidence-review.md)、[EHR 评测集普查](ehr-eval-construction-survey-benchmarks.md)、[方法学笔记](ehr-eval-construction-survey-methodology.md)、[调研主报告](ehr-eval-construction-survey.md)）。本报告只做决策层综合与执行路径修订；所有数字的出处见对应笔记。

## 1. 跨五维的四条结构性规律（本次新证据）

1. **分数 = 决策时点信息量 × gold 轨道选择，任何单轨报告都会系统性误导排名。** 四组独立证据同向：Hager（Nat Med 2024）同一模型自主索取 vs 全信息差 **−11~−13 个百分点**（45.5→58.8 等）；ClinDiag 动态 vs 静态差 **−17~−27**；MEDDxAgent 仅主诉 0.18/0.07 → 补 2–3 轮信息 0.86/0.56（超过全档案直读 0.69）；LA-CDM 全开上界 92.8%@$3,793 vs 学习策略 81.3%@$1,296。**含义：每维题目的快照信息量是难度旋钮，必须显式声明并分层报告**（ED 初诊少信息题与 24h 修正多信息题应成对设计）。
2. **行为≠规范的偏离在各维都有 40–50% 量级的实证基线。** sepsis bundle 合规约 50%；出院用药重整不一致 41%；结肠镜 surveillance 间隔依从 48.8%；肿瘤治疗 minor 层不合规约 75%（Major 12.4%）；门诊影像转诊不适当 26–75%。**含义：双轨并行、分开报告不是偏好而是必需——只报行为轨会把不合规实践法定为正确答案，只报规范轨则脱离真实系统行为。**
3. **过程 gold ≠ 结局 gold。** Optimization Paradox（Stanford，MIMIC-CDM 1,190 test）：组件最优系统过程指标胜率 76–84% 而诊断胜率仅 8.0%；coverage-to-test ratio 与诊断准确率零相关（Spearman ρ=−0.057）。**含义：指南覆盖类过程指标只能作辅助报告，"检查开得全"永远不能单独当"检查选得对"的判据。**
4. **高共识区出行为题、低共识区出专家双轨题。** MIMIC-CDM 中阑尾炎切除推荐共识 97.5%（行为 gold≈规范 gold 的区域）；Gaber 数据中"多专科均合理"使 matched 与 at-least-one 差约 10 个百分点（唯一答案天然稀缺的区域）。**含义：题目应按"共识度"分层建库，而不是按维度一刀切地选 gold 轨道。**

## 2. 五维 gold 方案细化

### 2.1 检查检验选择

| 设计项 | 细化结论（新证据） |
|---|---|
| 行为 gold | POE `transaction_type='New'` 订单簇为一个"决策回合"（回合窗 60 min【推断，需用 MIMIC-IV 分布校准】）；剔除 discontinued 与 24h 内同亚型重复；**标签聚合到检验类别/影像模态**而非逐项（Hager 类别化先例：类别化既有可行性——OASST 炎症类 93.3%——又病理特异——酶类仅 56.5%） |
| 时间语义 | 问"开什么"锚 `ordertime`；问"结果怎么解读"才锚 charttime（LabTOP 实证绝对时间编码 NMAE 0.064 vs 相对 0.134） |
| 规范 gold | 指南推荐检查集做 **coverage 辅助报告**（Optimization Paradox 手工整理先例）＋ Choosing Wisely **负向题**（"最应避免哪项"——SycoEval-EM 判卷人机 κ=0.957 先例）＋ ≥2 专家对行为答案裁"可接受/次优/不当"；干扰项可引入成本维度（LA-CDM：等诊断收益下更低价检查） |
| 修正点（vs 旧报告） | 旧报告的 pattern/rule-concordance 设计不变；新增三点：(a) 类别化 gold 降低逐项噪声；(b) 索取式评测的幻觉结果风险（13.87%）在 MCQ 形式下天然规避——这是坚持 MCQ 的又一依据；(c) **本维规范性评测是文献空白**（ClinDiag 检查阶段只做 Likert 评分无对错 gold）——做出可判定的检查 gold 即是论文级增量 |
| 排除/人工 | 亚型→类别映射表一次性质控；回合切分抽检 5–10%；CW 场景撰写与专家裁定须人工 |

### 2.2 临床诊断

| 设计项 | 细化结论 |
|---|---|
| 行为 gold | 出院主诊断（`diagnoses_icd.seq=1`）× 出院小结诊断段**交叉验证**，冲突者进人工队列；双决策点：ED 段末与住院 24h【推断】；快照做**诊断词去标识扫描**（Hager 先例：不做则自主评测被泄漏摧毁） |
| 规范 gold | **2+1 专家协议**（Open-XDDx 570 例样板：2 医生独立 + 第三人仲裁，均 4.6 个 DDx/例）；注意 Open-XDDx 自述**无排序信息**——我们的协议必须额外收集"最可能"排序判断；3–5% **确诊级锚题**（病理/微生物可确认病例，AMIE/CPC 精神）标定专家与模型差距 |
| 题型修正 | AMIE 三臂表显示模型"鉴别面宽而定诊力弱"（top-1 29.2% vs 医生 15.9%，但 top-10 59.1% vs 33.6%）——诊断维应并存"当前最可能诊断"与"最需纳入鉴别/排除"两类题干【推断】 |
| 干扰项 | 按 H-DDx 层次化思想从"同层次混淆病"（同解剖系统/同表现簇）生成，专家确认"该时点可辩" |
| 成本锚点 | EHRNoteQA：3 医生×2 月 / 962 题，**33.8% 的正确答案被改**（高于题干修改率 20.6%——自动 gold 的主要错误在"病历事实→可判定答案"的映射，本项质控重心）；MCQ 判卷方差 SD 0.24 vs 自由文本 1.21（MCQ 主形态的又一证据） |

### 2.3 治疗处置

| 设计项 | 细化结论 |
|---|---|
| 行为 gold（事件分层） | **T1** 开立/处方（POE+prescriptions，考决策意图）；**T2** 执行（eMAR，可识别 held/refused）；**T3** 手术/操作（**procedures_icd + 出院小结文本双源**——MIMIC-CDM 原文引证：ICD 表漏掉大量手术，必须文本补齐）。eMAR 与 POE 的分歧本身可作题目素材（开了没给=需专家裁定） |
| 规范 gold（工具分层） | **N1 可自动**：bundle/essential 类（SSC/SEP-1 元素自带时间窗与剂量标准，输入是结构化事件流——三维中唯一可自动判定的规范 gold）；**N2 半自动**：Beers 2023 / STOPP-START v3 清单命中（≥65 岁，RxNorm/ATC 映射）；**N3 人工**：MAI 式逐药裁定（10 条目 rubric），**双人配对用药师+医师**（κ 0.83）而非双药师（κ 仅 0.59） |
| 关键陷阱 | 行为 gold 把不合规当正确（SEP-1 基线合规约 50%）；**漏开只有 START 能打分，行为轨永远测不出**；NCCN concordance 22–92% 的定义敏感性 → 规范判定必须锁死"指南版本+时间窗+分期锚点"，且**分期锚点须来自决策时点前信息**（OCCPI III 期 OR 22.07 的循环警示：III 期由术后病理定，而化疗决策在术后）；**无过敏/禁忌证据的病例禁止出"为什么没开 X"类规范性题**（MIMIC 无结构化过敏表，禁忌证据靠 notes） |
| 出题区 | 高共识区（如阑尾切除 97.5%）出行为题；低共识区（支持治疗强度、晚期分流）只出专家双轨题 |

### 2.4 转诊与科室选择

| 设计项 | 细化结论 |
|---|---|
| 行为 gold（事件分层） | **R1** services 团队变更（住院场景，负责团队语义）；**R2** poe consult 医嘱（ED 场景，时点=开立时刻，天然的"决策"痕迹）；**R3** transfers 仅作辅助特征（床位管理噪声：感染控制、容量） |
| 规范 gold | **无国际通用转诊适当性量表**（本次工具箱核实的结构性空缺）——只能用指南内嵌转诊指征（脓毒症→ICU、STEMI→导管室、ACR 类标准）+ 本地路径；专家裁定按**三轴**：必要性 / 目标科室 / 紧急度 |
| 关键修正（最强的新证据） | (a) **绝不用 LLM 映射诊断→专科造 gold**：Gaber 的 LLM 生成专科 gold 经 4 名医生验证，"Accurate"率 68.94–93.77%、最严医生"彻底错误"率 9.15%（其论文平均值 97.03%"准确或可接受"掩盖了分歧幅度）；我们数据里有真实 consult/services 事件，直接用；(b) **多专科合理性 ~10pp** → MCQ 化前必须做唯一性过滤，否则 gold 不唯一；(c) **ESI 行为 gold 天花板**：评分者间 κ≈0.79、护士情景准确率 ~59% → 相邻级别干扰项不能算"明确错误"，需非对称计分或专家重裁 |
| 香港适配 | **三维中风险最高**：美国单中心科室结构≠HA 专科体系，规范性 gold 须整体重建（HA 转介指引/急症分流协议）；门诊转介在 MIMIC 不可得（无出院后门诊数据），只能考住院内会诊与 ED 转科 |

### 2.5 离院指导与随访

| 设计项 | 细化结论 |
|---|---|
| 行为 gold（降级为 F1 文书轨） | MIMIC 内真实随访事件（F2）**基本不可得**——行为轨只剩出院文书内容（F1），按**四子轴离散化**：随访科室 / 随访时间窗（≤1 周、1–4 周、1–3 月、3–12 月、3–5 年【推断档位】）/ 带药变更（新开/停用/调整，prescriptions×文书双源）/ 红旗症状覆盖 |
| 规范 gold | 病种 **surveillance 间隔表**（可半自动、间隔离散天然适合 MCQ；依从仅 48.8% 证明行为大面积偏离规范）+ **MedRec 式带药比对**（入院前用药×出院带药，专家双人；41% 不一致率证明文书本身有噪底）+ Wimsett 清单仅作质量监测（不作 MCQ gold） |
| 关键陷阱 | **随访维专家一致性全项目最低**（随访动作 κ 0.52–0.57 vs 用药 0.85+，Ayre）→ 单题裁定轮次最多，双人+仲裁不可省，优先离散 MCQ 化而非自由文本比对；Ayre 18% 有害率（6% 幻觉、3% 新增药物、剂量加倍实例）→ 这些"看似合理实则有害"的内容是**高质量干扰项的天然素材** |
| 阶段策略 | "最佳随访"规范性主榜可考虑推迟到香港阶段（HA 有 SOPC 门诊预约与再入院数据，可补 F2 真实随访事件——随访维在香港反而可能成为数据最全的一维） |

### 2.6 五维横向对比（更新）

| 维度 | 行为轨可自动化 | 规范轨工具成熟度 | 行为-规范偏离基线 | 专家一致性风险 | 建议顺序 |
|---|---|---|---|---|---|
| 检查检验 | 高（POE 语义清晰） | 中（指南集须逐病理整理；CW 负向可用） | coverage 与结局零相关 | 中 | **第 1 闭环**（不变） |
| 诊断 | 中（ICD×文本交叉） | 高（2+1 协议成熟） | 编码后验性 | 中（i2b2 intuitive 0.44 预警） | 第 2 闭环（不变） |
| 治疗 | 高（多源可交叉） | **最高**（bundle 可自动+清单半自动+MAI） | sepsis ~50% | 低-中（MAI 0.83 配对） | 第 3 闭环，**N1 bundle 子轨可与诊断维并行启动**（修订） |

## 3. 实体/关系抽取如何开展（与项目 NER v2 的对接）

### 3.1 现有 v2 schema 对照文献建议

| 分块抽取、确定性 span 回填 | 文献无直接实证（已诚实标注） | 按 NER 笔记 4.3 的五条保守规则执行：文档坐标系标注、chunk 重叠 64–128 token、跨 chunk 关系仅文档级合并、接缝 linter、阶段 4 量化边界损失 |

### 3.2 分阶段执行摘要（详见 NER 笔记第 6 节）

- **阶段 0（1–2 周）**：下游两张映射表（快照证据/泄漏防控）反推 schema；指南 v0 按十三章模板（含本项目特有的"不标注三态语义"：显式否定标 absent / 未提及不标 / 模板噪声跳过）；IAA 脚本三件套先行（对称 exact/partial F1、属性 κ/α+per-value、关系 L1/L2）。
- **阶段 1（3–5 轮 pilot）**：每轮 20–30 份、4 类文档分层；退出条件：指南变更归零 + 实体 exact F1（放射 ≥0.90、其余 ≥0.85）两轮不降 + 断言 α≥0.75、时点 α≥0.70、主体 α≥0.70 + 关系 L1 κ≥0.60 + 每类 ≥30 实例。
- **阶段 2（正式双标+裁决）**：A/B 空白文档起步（**模型输出绝不进标注界面**——South 预标注未提高 IAA + Wang CHI 2024 错误标签传染证据）；裁决按四类归因（边界/类型/遗漏/指南缺陷）；每批跑一致性 linter；每 100 份插 1 份锚文档防漂移。
- **阶段 3（门禁解锁）**：分层判定；低于 α 0.667 的层降级为"辅助层"；未达标类型走小循环或合并（i2b2 7→3 先例）。
- **阶段 4（模型对齐评估）**：现有 300 例 `unreviewed_model_output`（12,596 实体/919 关系）在此消费——双口径×双任务×分层（类型/属性值/文档类型/距 chunk 边界距离），对照 RadGraph 先例预期"实体对齐好于关系对齐"（模型-人类差距：实体 −0.05 vs 关系 −0.13）。

## 4. 修订后的总体执行路径

对 README 现行关键路径（归一化试审 → 协议冻结 → snapshot/gold → NER calibration → 检查题闭环 → 逐维扩展 → 香港适配）的**修订建议**（顺序主干不变，四处细化）：

1. **不变**：跨批归一化 100 条试审仍是最高优先门禁（charter+codebook 先行，PPV+Wilson CI 三档处置）。
2. **新增并行线**：NER **阶段 0 可立即启动**（schema v0 + 指南 v0 + IAA 脚本，不依赖归一化完成）；阶段 1 pilot 双标紧随。现有 200 份 pilot 的 50/150 患者隔离与 A/B 同任务设计正好映射到阶段 1/2。
3. **协议冻结时一次性锁死四件事**：统计口径（患者聚类 bootstrap CI + 多重比较校正）、canary GUID 与私有镜像方案、检查题类别聚合表版本、诊断词去标识扫描规则。
4. **逐维顺序微调**：检查（第 1 闭环）→ 诊断（2+1 协议试点）→ **治疗 N1 bundle 自动轨可与诊断并行**（可自动判定的规范 gold，边际成本最低）→ 离院（降级为 F1 文书四子轴轨）→ 转诊（最后；正式题库放香港阶段）。治疗 N3（MAI 裁定）与离院规范轨按剩余预算排。
5. **每题从第一题开始留痕**：生成模型+版本+prompt hash、审题人、修改类型（删/改题干/改答案/改干扰项）——EHRNoteQA 口径（24% 题干被改或删）是预算与论文披露的锚。
