# patients 表

## 概述

`patients` 表是MIMIC-IV中最基础的患者信息表，存储患者的人口统计学信息。每个患者在此表中有且仅有一行记录。

## 表结构

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|----------|------|------|
| `subject_id` | INTEGER | NOT NULL, 主键 | 患者唯一标识符 |
| `gender` | VARCHAR(1) | NOT NULL | 患者性别 |
| `anchor_age` | INTEGER | NOT NULL | 锚定年龄 |
| `anchor_year` | INTEGER | NOT NULL | 锚定年份（去标识化后的年份） |
| `anchor_year_group` | VARCHAR(255) | NOT NULL | 真实年份范围 |
| `dod` | TIMESTAMP(0) | 可空 | 死亡日期（去标识化） |

## 字段详解

### subject_id
- **含义**: 患者的唯一标识符，用于在整个数据库中追踪患者
- **ETL映射**: 对应医院系统中的患者ID或病历号
- **使用说明**: 此字段是连接所有患者相关表的核心外键

### gender
- **含义**: 患者的生理性别
- **取值**: `M`（男性）, `F`（女性）
- **ETL映射**: 对应医院系统中的性别字段

### anchor_age
- **含义**: 患者在 `anchor_year` 时的年龄
- **特殊处理**:
  - 年龄超过89岁的患者，年龄被设置为91以保护隐私
  - 这意味着所有91岁的记录实际上代表≥89岁的患者
- **ETL映射**: 根据出生日期和入院日期计算

### anchor_year
- **含义**: 去标识化后的锚定年份
- **说明**: 这是一个虚构的年份（通常在2100年代），用于替代真实年份
- **用途**: 与 `anchor_year_group` 配合使用，可推算真实年份范围

### anchor_year_group
- **含义**: 患者数据对应的真实年份范围
- **取值示例**: `2008 - 2010`, `2011 - 2013`, `2014 - 2016`, `2017 - 2019`
- **用途**: 用于需要考虑医疗实践时间变化的研究分析

### dod (Date of Death)
- **含义**: 患者的死亡日期
- **数据来源**:
  - 医院记录（院内死亡）
  - 马萨诸塞州生命统计登记处（院外死亡）
- **重要限制**:
  - 院外死亡数据仅覆盖最后一次出院后一年内
  - NULL值表示患者在该时间点仍存活，但不能推断一年后的生存状态
- **ETL映射**: 对应医院系统中的死亡记录

## 年龄计算示例

假设一条记录：
- `anchor_age` = 50
- `anchor_year` = 2150
- `anchor_year_group` = "2011 - 2013"

解读：
1. 该患者在去标识化年份2150时为50岁
2. 真实年份实际在2011-2013年间
3. 若该患者在去标识化年份2152有入院记录，则当时年龄为52岁

## 外键关系

| 关联表 | 关联字段 | 关系 |
|--------|----------|------|
| admissions | subject_id | 一对多 |
| transfers | subject_id | 一对多 |
| labevents | subject_id | 一对多 |
| 所有其他临床表 | subject_id | 一对多 |

## ETL映射建议

1. **患者ID映射**: 建立本地患者ID到 `subject_id` 的映射表
2. **性别标准化**: 将本地性别编码转换为 `M`/`F`
3. **年龄处理**:
   - 计算入院时年龄
   - 对≥89岁患者统一设置为91
4. **日期偏移**:
   - 为每个患者生成随机日期偏移量
   - 保持同一患者所有日期的相对关系

## 注意事项

1. 此表不包含种族、民族等敏感人口统计信息（这些在admissions表中）
2. 死亡日期的一年限制是研究设计时必须考虑的重要因素
3. 年龄截断（89岁）会影响老年患者相关的统计分析
